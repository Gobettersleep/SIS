## 一、项目概述

### 1. 项目背景
本项目来源于高校日常教学管理需求。目前学生信息、课程信息及成绩管理仍然依赖传统手工记录或分散的电子表格，存在数据冗余、查询不便、易出错等问题。开发一个统一的大学生信息管理系统，能够提高信息管理的效率与准确性，方便教师和学生随时查阅与维护相关信息，具有现实的应用价值。

### 2. 项目目标
本系统旨在实现一个基于Web的大学生信息管理平台，主要目标包括：
- 提供学生信息的增删改查功能；
- 提供课程信息的增删改查功能；
- 提供学生成绩的录入、修改、查询与删除功能；
- 实现基本的用户登录与身份验证，保障系统安全；
- 采用前后端分离架构，确保系统可维护性与可扩展性。

### 3. 开发环境与条件
- **开发工具**：VS Code、Navicat（数据库管理）、Postman（API测试）
- **前端技术**：Vue 3、Vite、Vue Router、Axios
- **后端技术**：Node.js、Express
- **数据库**：MySQL 5.7+
- **运行环境**：Node.js 14+，现代浏览器（Chrome、Edge、Firefox等）

## 二、技术路线

### 1. 总体架构
采用前后端分离架构：
- 前端：Vue 3单页面应用，通过Axios调用RESTful API。
- 后端：Node.js + Express框架提供API服务。
- 数据库：MySQL存储业务数据。
- 通信协议：HTTP/HTTPS，数据格式为JSON。

### 2. 主要技术

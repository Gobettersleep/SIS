### 1.4 关键问题及解决方案

| 问题               | 影响          | 解决方式                 | 状态    |
| ---------------- | ----------- | -------------------- | ----- |
| MySQL 8.0 认证协议变更 | 无法连接数据库     | 使用 mysql2 驱动替代 mysql | ✅ 已解决 |
| 中文乱码             | 中文数据显示异常    | 设置 utf8mb4 字符集       | ✅ 已解决 |
| 外键约束删除失败         | 级联数据无法清理    | 实现级联删除逻辑             | ✅ 已解决 |
| 数据库数据不同步         | 前端显示旧数据     | 更新后端交互逻辑，修改数据库配置     | ✅ 已解决 |
| CORS 跨域问题        | 前端无法请求后端API | 配置 Express CORS 中间件  | ✅ 已解决 |
| 前端路由守卫           | 未登录用户访问受限页面 | 实现路由拦截与登录验证          | ✅ 已解决 |
